Manager Library

Plataforma integral de gestión bibliotecaria construida con Arquitectura Onion en Laravel 11, interfaz reactiva en React + TypeScript y orquestación con Docker.

Abrir Aplicación Web ➔ Estado de la API (Health)
🧅

Arquitectura Onion

Separación estricta de responsabilidades: Dominio puro desacoplado, Casos de Uso con DTOs, Adaptadores en Infraestructura y Bootstrap en Service Provider.

⚡

React + Vite + TS

Experiencia de usuario de alto impacto con tema oscuro, filtros reactivos, modales fluidos, control de sesión JWT y navegación por roles (Admin y Bibliotecario).

🛡️

Invariantes de Dominio

Garantía de stock entre 0 y total, límite de 3 libros por socio, restricción estricta ante vencidos, fotos congeladas de líneas y soft deletes con índices parciales.
